# Pentesting Tools & Scripts

Welcome 👋  

I’m a penetration tester who occasionally writes small scripts to make repetitive tasks easier.  
Instead of keeping them to myself, I share them here so that others can benefit too.  

This repository is a collection of lightweight tools and snippets I’ve created over time.  
Each folder serves its own purpose — you can explore and use whichever fits your workflow.  

---

## 📂 Repository Structure

- **scanners/** → Scripts to automate host discovery and enumeration.  
- **xpath-injection/** → Helpers and proof-of-concept code for testing XPath Injection vulnerabilities.  
- *(more folders coming… each one is focused on a specific task or technique)*
